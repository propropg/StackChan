表情

LED

明るさは本体の安全範囲（各色 168/255 まで）に自動で抑えます。

VOICEVOX（クラウド）

VOICEVOX でしゃべる

オフ、またはつながらないときは従来の声（起動時は内蔵のあいさつ、Claude Code の通知は PC の声）でしゃべります。

キーは su-shiki.com/api で発行できます。空欄のまま保存すると、今のキーをそのまま使います。

1回あたり 1500 + 100 × 文字数（UTF-8のバイト数）ポイントを使います。1日の上限はおよそ 1,000 万ポイントです。

Claude Code の通知

{session} はセッション名に置き換わります。PC の Claude Code から届いた通知を、ここの設定でしゃべります。
